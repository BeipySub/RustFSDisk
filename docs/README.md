# 文档目录说明

本文说明 `docs/` 下的文档存放规则。冻结基线文档不得移动、重命名或修改。

## 目录结构

```text
docs/
├── 01-协议契约/
├── 02-方案设计/
├── 03-部署运行/
├── 04-原型设计/
├── 99-项目管理/
└── v1.0冻结/
```

## 存放规则

### 01-协议契约

存放 API、WebSocket、Dashboard 快照、字段契约、前后端通讯协议等文档。

### 02-方案设计

存放需求调整方案、KEY 模型改造方案、离线导入导出改造方案等实施设计文档。

### 03-部署运行

存放 Linux、Windows、VM、本地联调、部署运行、开发环境启动等手册。

### 04-原型设计

存放 UI 原型、视觉稿、产品设计交接和相关图片资产。

### 99-项目管理

存放上线要求、debug 待修复列表、排查记录、交付检查等项目管理类文档。

### v1.0冻结

存放 v1.0 冻结基线文档。该目录已冻结，禁止修改、移动、重命名或删除。
