## Edge 热插拔 WebSocket 空扫描事件修复

  - 未修改 HTTP summary、WS 字段结构、前端类型、导出、导入、加密、SQL。

## Edge 热插拔 rescan 延迟优化

  - 更新 systemd README，明确 rescan service 不挂载、不固定等待，只立即通知 Edge 扫描当前设备状态。

## Edge 已挂载非 ext4 USB 盘卡片闪现后消失修复

- 范围：修复 USB 盘插入后先显示卡片，随后因系统自动挂载到 `/media/edge/...` 又从前端消失的问题。
- 根因：`ConfiguredMountProbe` 对已挂载候选盘执行了 `无协议文件 + 非 ext4` 直接过滤；未挂载 NTFS 盘能进入拒绝展示，挂载后的 NTFS 盘反而被过滤，后续扫描将旧 runtime 标记为 `REMOVED`。
- 修复：
  - 已挂载候选盘如果来自 USB block device，即使无协议文件且非 ext4，也进入统一 `evaluate_disk` 判定。
  - 该盘稳定展示为 `REJECTED / FILESYSTEM_UNSUPPORTED`，不进入任务池，不影响 ext4 初始化运输盘 READY 主流程。

## Edge 插盘偶发不实时显示修复

- 范围：修复删除 rescan 固定等待后，插盘时 udev 早于分区识别或挂载完成，导致前端偶发不显示的问题。
- 根因：拔盘不需要等待 Linux settle，立即扫描可以秒级删除卡片；插盘需要覆盖 `disk -> partition -> filesystem -> mountpoint` 的异步识别过程，单次立即扫描会遇到半成品设备状态。
- 修复：
  - `DiskRescanCoordinator` 对 `Udev` 触发保留立即扫描。
  - 立即扫描后固定追加 300ms 和 2s 两次 follow-up rescan。
  - 有并发 udev 事件时仍按原逻辑合并为一次 queued rescan，避免事件风暴。
- 验证：
  - `cargo fmt --all -- --check`
  - `cargo test -p rustfs-transfer-edge`
  - Edge VM 已同步 `rescan.rs`，服务 `/readyz` 正常。
  - 当前 `/dev/sdb1` 插入状态下 dashboard summary 返回 `REJECTED / FILESYSTEM_UNSUPPORTED` 卡片。

## Edge 历史已导出对象版本去重

- 范围：补齐 Edge 创建导出任务时的本地历史导出去重，避免同一 RustFS 对象版本在后续导出任务中重复写盘。
- 规则：
  - 扫描仍记录最新 RustFS 快照和稳定性。
  - 创建导出计划时排除历史 `export_job.status = SEALED` 且 `export_object.status = EXPORTED` 的同一对象版本。
  - 对象版本身份使用 `bucket + object_key + etag + size_bytes + last_modified`。
  - 未封盘、失败或取消任务中的 `EXPORTED` 记录不作为跳过依据，避免误跳过导致数据未交接。
- 修复：
  - `create_export_plan_from_stable_snapshots` 查询最新稳定快照时增加 `NOT EXISTS` 历史封盘导出排除条件。
  - `PgObjectSnapshotRepository::enqueue_export_object` 老入口同步增加相同排除条件。
  - 新增 `sql/edge/0006_export_dedup_index.sql`，为历史 `EXPORTED` 对象版本查询建立局部索引。
- 验证：
  - `cargo fmt --all -- --check`
  - `cargo test -p rustfs-transfer-edge`
  - `cargo test -p rustfs-transfer-edge websocket_scan_ticker_does_not_repeat_terminal_done_snapshots`
  - `cargo test -p rustfs-transfer-edge`
  - Edge VM 源码同步后由 cargo-watch 重启，`/readyz` 正常。
  - 临时候选盘触发 rescan 后，WS 首批事件为 `DISK_PLUGGED`，不再重复发送 `COPY_PROGRESS / SCANNING_RUSTFS / DONE / disks=[]`。
