# work_sprint 工作任务目录

本目录用于记录 2 天 Sprint 的任务拆分、领取状态、并行开发安排和每日开发记录。

## 目录约定

- `TASKS.md`：2 天 Sprint 任务总表、并行泳道、不可降级底线和任务卡片。
- `dev_log/`：每日开发任务记录目录。
- 每天一个独立 Markdown 文件，文件名以当天日期为准，格式为 `YYYY-MM-DD.md`。

## 任务状态

- `[ ]`：未开始。
- `[~]`：开发中。
- `[x]`：开发完成。

开发者或 AI 代理领取任务前，先阅读根目录 `AGENTS.md` 和 `TASKS.md` 中对应任务卡片。
